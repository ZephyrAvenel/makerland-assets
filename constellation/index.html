Lieu vivant Constellation

Les liens entre toutes les oeuvres.

La Constellation rassemble les traces laissees par les lecteurs: non pour les classer, mais pour montrer comment les recits continuent de vivre.

Comment nait un recit ?

Chaque etoile de la Constellation garde la trace d'un chemin de creation: une intuition, un dialogue, une forme, puis une rencontre avec un lecteur.
