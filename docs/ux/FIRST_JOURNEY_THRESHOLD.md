# UX-021 - Seuil et transition vers le Premier Voyage

## Principe

Le visiteur doit d'abord rencontrer le seuil de Makerland.

Ce seuil n'est pas une etape du Premier Voyage. C'est un lieu de choix : decouvrir, poursuivre ou explorer librement.

## Parcours

Le parcours d'initiation devient :

Accueil

-> Seuil

-> Votre premier voyage

-> Meteo

-> Bibliotheque Vivante

-> Atelier IA

-> Archive D001

-> Constellation

-> Fin du voyage

## Role du seuil

Le seuil conserve :

- la grande illustration plein ecran ;
- le titre Bibliotheque Vivante ;
- la promesse centrale ;
- les trois portes d'entree.

Il ne porte aucun tutoriel et aucune carte pedagogique.

## Page intermediaire

La porte `Je decouvre` n'ouvre plus directement le Premier Voyage.

Elle affiche une page de transition :

`Votre premier voyage`

Cette page explique que les Recits Vivants se traversent progressivement. Elle propose deux actions :

- commencer le voyage ;
- revenir au seuil.

## Debut du Premier Voyage

Le Premier Voyage commence maintenant a la Meteo interieure.

La Meteo devient la premiere experience d'orientation sensible avant la Bibliotheque, l'Atelier, D001 et la Constellation.

## Regle UX

Le visiteur franchit un seuil avant d'entrer dans le recit.

Il choisit d'abord son mode d'entree, puis comprend qu'il s'apprete a traverser cinq lieux essentiels.
