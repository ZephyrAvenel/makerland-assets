# UX-019 - Le Fil Rouge de Makerland

## Philosophie

Le Fil Rouge aide le visiteur a comprendre Makerland sans transformer l'experience en tutoriel.

Il rappelle discretement que Makerland n'est pas une suite de pages, mais un territoire de creation ou une idee peut devenir une oeuvre, laisser une memoire, entrer en relation avec d'autres formes, puis rejoindre le voyage du lecteur.

## Cycle narratif

Le parcours suggere suit une logique simple :

Intuition -> Atelier -> Oeuvre -> Memoire -> Liens -> Transmission

Cette structure n'est jamais imposee. Elle apparait par petites phrases, par transitions douces et par une carte discrete du territoire.

## Role des lieux

- Accueil : ici commence la traversee.
- Meteo interieure : ici vous choisissez votre premier climat.
- Boussole Vivante : ici une direction peut apparaitre sans jamais s'imposer.
- Cartes Narratives : ici les idees deviennent des chemins.
- Bibliotheque Vivante : ici vivent les oeuvres publiees.
- Atelier IA : ici les idees prennent forme.
- Archives Vivantes : ici se conserve la memoire de leur naissance.
- Constellation : ici apparaissent les liens entre les oeuvres.
- Carnet de Voyage : ici se poursuit votre propre voyage.

## Parcours du primo-visiteur

Le visiteur est d'abord accueilli par UX-018.

Puis, lorsqu'il traverse les grands lieux, UX-019 lui donne quelques reperes :

- le role du lieu ;
- une reponse courte a la question "Pourquoi cette salle ?" ;
- une carte simple du territoire ;
- une suggestion de suite possible.

Ces elements restent secondaires. Ils n'interrompent jamais la navigation.

L'accueil et la Meteo interieure conservent leurs propres mises en scene. Le Fil Rouge commence visuellement a partir de la Boussole afin de ne pas concurrencer les seuils deja stabilises.

## Vocabulaire

Le premier niveau evite les termes specialises.

Exemples :

- "Narratologie dialogique" devient "une maniere de creer qui progresse grace au dialogue".
- "Archives patrimoniales" devient "les coulisses de la creation".
- "Graphe relationnel" devient "les liens entre les oeuvres".

Les termes precis peuvent rester dans les documents approfondis, mais l'orientation initiale reste simple.

## Principes scenographiques

- Les encadres sont courts.
- Les transitions durent environ deux secondes.
- Rien ne bloque l'interaction.
- Les cartes disparaissent ou se simplifient en mobile.
- La Boussole, la Bibliotheque, l'Atelier et la Constellation gardent leur identite visuelle.

## Evolutions possibles

Le Fil Rouge pourra plus tard etre etendu aux pages internes :

- salles de l'Atelier ;
- Archives Vivantes D001-D010 ;
- Carnet de Voyage ;
- Constellation des Voyageurs.

Cette extension devra rester autonome et respecter la meme sobriete.
