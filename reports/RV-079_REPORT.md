# RV-079 - La Cosmologie de Makerland

## Resume

La mission ajoute la representation conceptuelle et visuelle officielle de Makerland.

Elle complete les documents fondateurs existants avec:

- une documentation d'accompagnement;
- une carte SVG vectorielle reutilisable;
- un lien depuis le README.

## Fichiers crees ou modifies

- `docs/vision/MAKERLAND_COSMOLOGY.md`
- `docs/vision/assets/MAKERLAND_MAP.svg`
- `README.md`
- `reports/RV-079_REPORT.md`

## Carte SVG

Le fichier `MAKERLAND_MAP.svg` represente:

- les sept lieux principaux;
- les relations Bibliotheque -> Boussole -> Cartes -> Oeuvres -> Constellation -> Carnet;
- le cycle Atelier -> Oeuvres -> Constellation -> Atelier;
- le Cycle Vivant;
- les trois niveaux du territoire;
- les verbes fondateurs.

Le SVG est vectoriel, autonome et reutilisable dans la documentation, le README, les presentations et de futurs supports.

## Document d'accompagnement

`MAKERLAND_COSMOLOGY.md` explique:

- la logique de la carte;
- le role des sept lieux;
- les relations narratives;
- le Cycle Vivant;
- les niveaux du territoire;
- les futurs developpements possibles.
